# مکتب النور

وب‌سایت اطلاع‌رسانی مجموعه‌ی فرهنگی و آموزشی «مکتب النور» با تم سیاه و سفید، انیمیشن و عناصر قرآنی.

## بخش‌ها
- **خانه**: اسلایدر تمام‌عرض «عکس‌های منتخب» با افکت ورق‌خوردن، معرفی، آخرین گزارش‌ها، برنامه‌ها، اطلاعیه‌ها و مقالات
- **گزارش‌ها**: به تفکیک **دوره** (پیش‌فرض ۱۷ تا ۲۳) به‌همراه بخش ویژه‌ی **فارغ‌التحصیلان**؛ هر دوره صفحه و رنگ شاد خودش را دارد. بازه‌ی دوره‌ها از پنل مدیریت ← تنظیمات (`course_first` و `course_last`) تغییر می‌کند.
- **ویدیوها**: در پنل مدیریت ← گزارش‌ها، فیلد «ویدیوهای آپارات» (هر خط یک لینک مثل `https://www.aparat.com/v/xxxxx`) پخش مستقیم از آپارات را در همان گزارش می‌گذارد. لینک کانال از تنظیمات ← «لینک کانال آپارات» تغییر می‌کند. (در CSP سرور فقط `www.aparat.com` برای iframe مجاز است.)
- **برنامه‌ها**: ۱۰ دسته‌ی ثابت: اردوی مشهد، اردوی اربعین، اردوی پاییزی، اعتکاف، اردوی زمستانی، کلاس‌های تابستانی، ضیافت نور، برنامه‌های تفریحی، برنامه‌های ورزشی، جلسات دوره‌ای
- **افراد**: مربیان به تفکیک دوره
- **اطلاع‌رسانی**، **مقالات**، **درباره‌ی ما** (پیشینه‌ی جلسات حفاظ القرآن)، **تماس با ما**
- **پنل مدیریت** در `/#/admin` برای افزودن، ویرایش و حذف همه‌ی محتوا (از جمله اسلایدر اصلی)، دیدن پیام‌ها و ویرایش تنظیمات (آدرس، ساعت، تلفن، متن درباره‌ی ما)

## اجرا
نیازمند Node.js نسخه‌ی ۲۲.۵ یا بالاتر.

```bash
npm install
ADMIN_PASSWORD="رمز-دلخواه" npm start     # http://localhost:3000
```
اگر `ADMIN_PASSWORD` تعیین نشود، در اولین اجرا یک رمز تصادفی ساخته و در کنسول و فایل `data/.admin-password` نوشته می‌شود.
در سرور واقعی `NODE_ENV=production` را هم بگذارید و پشت HTTPS اجرا کنید.

## ساختار
```
server/   index.js (Express، هدرهای امنیتی)، routes.js (API)، auth.js (ورود مدیر)، db.js (SQLite)
public/   index.html، css/style.css، js/app.js (صفحه‌ها و پنل)، js/api.js، js/ornaments.js، data/seed.json
data/     پایگاه‌داده و تصاویر آپلودشده (ساخته می‌شود؛ از آن نسخه‌ی پشتیبان بگیرید)
scripts/  build-preview.js
```

## API
| مسیر | دسترسی |
|---|---|
| `GET /api/{reports,programs,people,announcements,articles}` و `/:id` | عمومی |
| `POST/PUT/DELETE` همان مسیرها (فرم چندبخشی با `images`) | مدیر |
| `GET/PUT /api/settings` | خواندن عمومی، نوشتن مدیر |
| `POST /api/messages` | عمومی (محدودیت نرخ) |
| `GET/DELETE /api/messages` | مدیر |
| `POST /api/auth/login`، `/logout`، `GET /api/auth/me` | — |

## امنیت
رمز عبور فقط روی سرور، نشست در کوکی HttpOnly با SameSite=Strict، محدودیت تلاش ورود، آپلود فقط JPG/PNG/WebP تا ۵ مگابایت با بررسی امضای واقعی فایل، خروجی HTML همیشه escape می‌شود و CSP فعال است.

## فونت‌ها
وزیرمتن و امیری‌قرآن داخل `public/fonts` هستند و از گوگل بارگذاری نمی‌شوند، پس در ایران هم بدون مشکل نمایش داده می‌شوند.

## شخصی‌سازی
- **لوگو**: فایل‌های `public/img/logo-mark.png` و `logo-wide.png` (سیاه روی شفاف؛ روی زمینه‌ی تیره با کلاس `inv` سفید می‌شوند).
- **نقش اسلیمی**: در `public/js/ornaments.js` به‌صورت برنامه‌ای ساخته می‌شود و پس‌زمینه‌ی بخش‌ها و آیکون‌ها از آن می‌آید.
- **رنگ دوره‌ها**: آرایه‌ی `PALETTE` در `public/js/app.js`.
- **متن‌ها**: همه‌ی متن‌ها از پنل مدیریت ← تنظیمات قابل ویرایش‌اند. شماره‌ی تلفن تا وقتی خالی باشد نمایش داده نمی‌شود.
- **پیش‌نمایش تک‌فایلی**: `npm run build:preview` ← `dist/preview.html` (بدون بک‌اند، با داده‌ی نمایشی در مرورگر).
